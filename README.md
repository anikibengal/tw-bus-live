# 公車即時（tw-bus-live）

雙北公車的手機等車頁：關注的路線下一班幾分到、後面每一台車各幾分、現在該不該出門，另有即時地圖。

網址：https://anikibengal.github.io/tw-bus-live/

## 能做什麼

- **等車**：每個站各自選要看的路線與方向，每條路線一列大數字；點開看每一台車。站牌分成幾個候車位置（往東、往西、第幾月台），一次看一個。點開的明細裡有起站的末班發車時刻。
- **找公車**：打路線號碼、站名，或用定位找附近的站牌。涵蓋台北市與新北市。
- **地圖**：車的位置與幾分後到你等的站；點一台車看它接下來各站。
- **路線**：整條路線每一站的下一班與下下班；點你那一站之後的任何一站，看搭過去要多久、幾點到。

官方的預估到站每站只報最近的一班，也不說是哪台車。這個頁面把它對到車，再用前車剛跑過同一段的時間推算後面每一台。

## 限制

- 「最早 N 分」依 2026-10-03（週六）一天的記錄校準；拿沒用來校準的那一半檢查，約 85–90% 的情況車不會比它更早到。平日尖峰沒有驗證過。
- 車程（搭到某一站要多久）用同一天的兩段記錄檢查：車程 10–20 分平均差約 2 分、20–40 分約 3 分，白天偏短約 1 分。
- 新北市路線，以及 307、265區 以外的路線，推算準度還沒有用實際到站驗證過。
- 只在電腦上模擬的手機畫面測過，真實手機還沒完整測。
- 路線與站牌是建置當天的快照（`web/data/`），不會自動更新。
- 關注的路線與存起來的站只存在你的瀏覽器裡。定位只留在裝置上，不會上傳。

## 資料來源

- 車輛定位、預估到站、路線、站牌（含地址）、站序、路線軌跡：臺北市與新北市的公車開放資料（臺北市政府的開放資料主機 `tcgbusfs.blob.core.windows.net`，`blobbus/` 與 `ntpcbus/`），瀏覽器直接讀取。
  其中「新北市公車路線軌跡」資料集（政府資料開放平臺 160176，臺北市公共運輸處提供）依政府資料開放授權條款釋出：https://data.gov.tw/license 。
  即時檔的授權條款沒有找到明文，這裡比照標示來源。
- 307、265區 的路線、線型與班表：交通部運輸資料流通服務平臺（TDX）。
- 底圖：© OpenStreetMap 貢獻者。

## 在自己電腦上跑

```bash
python serve.py 8768        # 然後開 http://localhost:8768/
python -m unittest discover -s tests
node --test tests/core.test.js tests/calibrate.test.js
```

重建路線與站牌資料：`python pipeline/build_city.py`，再 `python pipeline/build_app.py`。

推到 `main` 會由 `.github/workflows/pages.yml` 把 `web/` 發布成網站。
